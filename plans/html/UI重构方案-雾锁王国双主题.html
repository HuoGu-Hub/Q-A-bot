1 体检：现状与问题

以下每一条都在 tests/screenshots/ui-before/ 的实测截图或页面尺寸里出现过，不是观感推测。重构要逐条消掉，不是换一套配色。

缺陷证据影响

1.2 一致性缺口

页面标题三种规格

  • 资料库 / 广场 / 关于：--fs-3xl 38px
  • 首页：clamp 42–68px 独立写法
  • 管理端：靠顶栏高亮，页面无标题

列表四种语言

  • 资料库结果：一列行 + 发丝线
  • 广场热词：两列行 + 英文名右对齐
  • 分类：带图标的卡片网格
  • 管理端：原生表格

同一控件多份实现

  • .search 在资料库与地图各写一遍
  • .chip / .tag-chip 三处实现
  • .err 提示条 12 个视图各写一份
  • .back 返回按钮三处写法不同

装饰互相打架

  • 雾层 + 噪点 + 径向光 + 角饰同时叠
  • 有的面板描边，有的只靠明度
  • 英文 eyebrow 大写小标签页面间不统一
  • 圆角 3 / 6 / 10 / 16 混用但无规律

1.3 重构的非目标

  • 不改任何接口、字段、路由、权限与业务流程
  • 不改后台可编辑文案的含义与默认值
  • 不新增页面、不删除功能入口
  • 不引入 UI 框架、CSS 预处理器或运行时依赖

2 设计方向：雾锁王国的五种材质

《雾锁王国》的界面语言可以归为五种材质。方案把每种材质落成一条可执行的规则，避免「加了一堆装饰但仍像模板」。

材质在游戏里的样子在本站落成的规则
石头地砖、墙基、火坛底座，表面粗糙、明度差小层级只靠背景明度阶梯与一道内阴影，不靠描边。全站只有 6 档石色，禁止就地取色
火火坛的橙黄色火焰，是全画面唯一的高饱和灵火色只用于「当前可操作 / 最该先看」的位置。一屏之内允许出现的高饱和区域不超过两处
雾远处被雾吃掉，边缘没有硬线分节不做整圈边框，用渐隐的刻线与留白断开；页面顶部一层偏心暖光，其余安静
羊皮纸地图、卷轴、配方书，米黄偏赭日间模式的底材。不是白底，是暖纸；纸张纤维用极低对比的噪点表达
铜饰箱角、门环、火坛铭牌上的暗金细线只做 1px 内衬线与标题刻痕，不描外框。比例控制在一屏内出现两次以内

2.1 签名元素：余烬刻痕

每一页的页面标题左侧、以及每个面板标题左侧，有一道 2px 的竖刻痕。夜间是余烬橙，日间是赭石；它不发光、不加渐变，长度固定等于标题字高。全站只有这一种「被点亮」的记号，除此之外不允许任何发光边框、渐变描边或霓虹阴影。

刻意保留的唯一风险：日间模式不是「白底 + 黑字」的安全解，而是米黄羊皮纸配赭石与青铜。它对长时间阅读更舒服，但需要更严格地控制对比度，因此日间的正文与次要文字都在 4.5:1 以上，装饰级文字单独一档并禁止承载内容。

2.2 两条主题的性格

雾夜 · 默认

绿黑石头，火坛亮着。背景不是纯黑，是带橄榄底的石板，靠近才能看出色相。文字是暖骨白而非纯白，长时间看不刺眼。灵火橙用于当前页、主按钮、被选中项。

日冕

雾散之后的白天。底材是日晒过的羊皮纸，面板比页面更亮，像纸页叠在桌面上。墨色偏褐不偏黑，灵火变成赭石。对比度按纸张反射率重算，不直接反色。

3 双主题令牌

所有颜色、阴影、描边都走 CSS 变量。两套值定义在 :root[data-theme="night"] 与 :root[data-theme="day"]，视图层不允许出现十六进制色值。变量名沿用现有 --stone-*、--ink-*、--ember*，保证 30 多个视图不需要改名就能吃到新主题。

4 排版与尺度

4.1 字体角色

角色字体用法
标题Noto Serif SC，自托管，已有 100 个子集页面标题、区块标题、中文显示字。字重 600，字距 .02em
正文系统无衬线：PingFang SC / HarmonyOS Sans / MiSans / 雅黑所有正文、控件、导航。各平台自带中文字体在小字号下比网络字体清楚
数据等宽：Cascadia Mono / SF Mono / Consolas数字、坐标、键名、时间、英文术语。一律 tabular-nums

4.2 字号阶梯

上一版有 9 档字号且相邻差值过小，标题看起来只是「更粗的正文」。收敛成 7 档，相邻至少 1.3 倍，移动端整体降一档但不改层级关系。

令牌桌面手机使用位置
--fs-micro11px11px徽标、计数、拉丁小标签。必须配 .06em 字距
--fs-xs12px12px说明、时间、次要元信息
--fs-sm13px13px表格、紧凑控件、辅助正文
--fs-base15px15px正文默认。手机输入框强制 16px 防 iOS 缩放
--fs-lg17px16px区块标题、面板标题、文章正文
--fs-xl20px19px小节标题、关键词标题

页面标题从 38px 收到 26px 是有意的：38px 在 1440 宽下会把页面压成「海报」，而站内真正需要大字号的位置只有首页。统一到 26px 之后，资料库、广场、关于、管理端标题一致，滚动手感也更像工具而不是宣传页。

4.3 间距与圆角

间距，4px 基准

4 / 8 / 12 / 16 / 24 / 32 / 48 / 72。纵向节奏只用这 8 档。页面左右内边距桌面 24，手机 16；区块之间 32，同区块元素之间 12 到 16。

圆角，三种含义

3px 刻痕与标签，6px 控件，10px 石板，16px 浮层与首屏，999px 药丸。并排控件必须同圆角；不许再出现 6px 输入框配 3px 按钮。

8 主题切换实现

8.1 状态与存储

// web/src/shared/theme/useTheme.ts
type Theme = 'night' | 'day'
const KEY = 'qqbot.theme'

// 首次访问跟随系统；用户手动切换后以存储为准
function initial(): Theme {
  const saved = localStorage.getItem(KEY)
  if (saved === 'day' || saved === 'night') return saved
  return matchMedia('(prefers-color-scheme: light)').matches ? 'day' : 'night'
}

// 落在 <html data-theme> 上，令牌选择器据此生效
apply(theme) // documentElement.dataset.theme = theme; colorScheme = theme === 'day' ? 'light' : 'dark'

8.2 防闪烁

两个入口 HTML 的 <head> 里各放一段 8 行内联脚本，在 CSS 解析前写好 data-theme 与 color-scheme。CSS 由 JS 模块引入，首帧不会先画成默认主题再翻色。

<script>
(function () {
  try {
    var t = localStorage.getItem('qqbot.theme')
    if (t !== 'day' && t !== 'night') {
      t = matchMedia('(prefers-color-scheme: light)').matches ? 'day' : 'night'
    }
    document.documentElement.dataset.theme = t
    document.documentElement.style.colorScheme = t === 'day' ? 'light' : 'dark'
  } catch (e) {}
})()
</script>

8.3 按钮形态

顶栏右侧一枚 36×36 图标按钮，夜间显示太阳、日间显示月亮，点击即切。可读名随状态变化：「切换到日间模式 / 切换到夜间模式」，同时更新 <meta name="theme-color"> 为当前页面底色。

8.4 与其他子系统的联动

  • 地图画布：MapCanvas 从 CSS 变量读色，主题切换时用 MutationObserver 监听 data-theme 重读并重绘，保证点位与文字在日间是深墨色
  • 轮播遮罩：图片上的控制条在两套主题里都保持深色半透明，因为底下永远是一张亮图
  • Emoji 与第三方内容：不引入，图标继续走 Icon.vue 的线性图标
  • 无 JS 环境：:root 默认给雾夜的完整令牌，页面仍可用

9.1 执行顺序为什么是这样

先令牌后组件，是因为组件只认令牌；先组件后外壳，是因为外壳要复用组件；先公开站后管理端，是因为管理端的表格与抽屉依赖公开站验证过的移动端规则。任何阶段都不会出现「改了一半、两套主题都难看」的状态。

13.2 与方案的偏差

  • 没有引入 Sheet 组件。手机地图控制栏直接给原来的 aside 加了一套「收起只剩 46px 把手、点把手展开」的样式，比另写一个弹层少一整份重复的图层列表标记。方案里的 Sheet 行已标注为不采用。
  • 没有建立 ActionBar。AdminPage 的动作行在手机上由「横滚」改成「换行 + 小号按钮」——横滚加右对齐会把第一颗按钮裁到屏幕外，实测出现过「全部展开」只剩「部展开」。收小之后四颗按钮正好一行，五个以上的页面折两行，比被裁掉一颗好。
  • 资料库与知识库加了客户端筛选。189 个分类、198 份文档一次性铺在手机上是十几屏。筛选是对已加载数据的本地过滤，接口与操作都没变；文档列表另外按每批 30 份渲染，避免一万像素的长页。
  • DataTable 的卡片模式设了 30 行上限。超过 30 行会退回表格 + 横向滚动：100 条记录每行一张卡会变成一万多像素，比横滑更难用。短表才卡片化。
  • 日间主题的正文对比度按纸张重算。没有直接反色：纸底是 #E9E1CF 而非白，墨色是 #2A2318 而非黑，灵火变成赭石 #9C5717，三个方向都过了 4.5:1。
