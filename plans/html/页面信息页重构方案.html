页面信息 · 后台重构

校样台

「页面信息」不是一个表单页，而是一张校样台：左边是你正在改的稿子，右边是它落到公开站上的样子。

这一页的职责

一个运营者，改一句会被群友立刻看到的固定文案。他要回答的只有四件事：改哪一句、这句现在长什么样、原来是什么、要不要退回去。所有结构都为这四件事服务，其余一概不进这一页。

色彩

沿用全站令牌，不新增颜色 —— 「雾中灵火」的身份已经由石头阶梯与灵火橙定义，另起一套才是破坏。这一页只固定它们的语义：

--stone-300 石板面 --stone-void 输入槽与校样条 --ember 已改动，唯一状态色 --ink-3 说明与默认值 --ink 正文

灵火橙在这一页只表达一件事：这里改过。左栏的火色竖轨与预览里改过的块是同一条规矩，两栏共用一套语言，学一次两处都认。

字体

沿用全站阶梯：条目名 --fs-body／正文色，说明与校样条 --fs-meta／三级色，状态计数 --fs-sm 半粗。不引入新字族 —— 这一页的性格由结构承担，不由字体承担。

布局

│ ▍  [ 输入槽 ]                              │                              │
│ ────────────────────────────────────────  │                              │
│   条目名                                   │                              │
│     [ 输入槽 ]                             │                              │
└───────────────────────────────────────────┴──────────────────────────────┘

▍ 是火色竖轨：改过 = 灵火，未改 = 发丝线。左栏是一条连续改下去的稿纸，所以不再套一层大面板；页面名也不重复，页签已经写着你在哪一页。

条目：一行状态 + 一行输入

一条文案只占两行：标题行（条目名 + 改过徽标 + 说明 + 动作）和输入槽。动作挂在标题行右侧、靠 margin-left: auto 顶到最右，不单开一行 —— 单开一行会把每条撑高，而这一页一屏要看十几条。没动过的条目一个字都不多。

撤销修改 恢复默认

两个动作分得很清：撤销修改丢弃还没发出去的一次编辑，恢复默认动的是公开站。两者都成立时两个都给 —— 否则「恢复默认」会顺手丢掉刚打的字。

不回显默认文本。这一条 2026-09-27 就定过：恢复默认是按钮的事，把原文摊在每块下面只是噪声。我在重构里一度把它以「校样边栏」的名义请了回来，现在按原判断收回 —— 要对照就去右边看改后的效果。它也不带底色与分隔线：这一页的色只讲一件事，灵火 = 改过。

砍掉的配件

  • 外层大面板的盒子与标题 —— 盒子套盒子让每块看着各自独立，反而看不出这一页一共改了几处。
    ⚠️ 只去掉那层结构，表面色照旧：仍是 stone-300 + 凸起 + 24px 内衬。去掉盒子时若什么都不补，这一列会落到页面底 stone-200 上，比右边的预览暗一档 —— 那是改布局时顺手带出来的颜色变化，不是设计决定，已还原。
  • 重复的页面名 —— 页签已经标出你在哪一页，标题再写一遍是重复。
  • 每块下面的填写帮助 —— 同一句话在十几块下面各来一遍就是噪声。整行删除：怎么写标记、能用哪些占位符，只在「填写说明」弹窗里说一次。
  • 标题行右侧的恢复按钮 —— 移到校样边栏里，紧贴它要恢复的值。
  • 默认文本的回显 —— 恢复默认是按钮的事，把原文摊在每块下面只是噪声。请回来过一版，又按原判断收回。
  • 改动块那层 10% 的橙底 —— 校样边栏进来之后，这层底会连它一起罩住， 一整块泛橙更像"选中态"。只留左边那条火色竖线，它正是预览栏标改过用的那条线。

没有做的事

  • 不做编号：文案块不是序列，序号编码不了任何真实信息。
  • 不换配色与字体：这一版的身份由结构与那一处灵火承担，所以一个令牌都没动，新元素也不带自己的底色。
  • 不动预览栏：它是这一页最有用的东西，只把它从「与编辑区同权的面板」变成「带框的一块屏」，figure 与 ground 这才分开。
