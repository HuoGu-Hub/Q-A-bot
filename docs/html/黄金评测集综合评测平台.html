黄金评测集综合评测平台设计

一、平台定位与总体架构

1.1 定位

评测中台是黄金评测集的执行器、留痕器与结算台：把已有检索黄金集与线上问答记录变成可重复执行的批次，把每条用例从输入到判定的七维过程固化成可回放的 span 树，把判定结果结算成可对比、可阻断、可导出的结论。

当前痛点系统里的证据平台交付
过程不可见qa_stat 只有检索摘要与三段耗时，工具调用只存在于日志文本，模型请求体、注入资料、引用映射都不落库span 树 + 七维展开 + 原始报文抽屉，单条用例可按时间轴回放到每次工具调用
失败难归因黄金集只到检索级，retrieval-golden.tsv 只判块命中；答案错、引用错、工具选错没有标签判定器 + 失败标签体系 + 归因决策树，每条失败产出可执行动作，指到术语、语料、阈值、提示词或工具
报告靠手工golden-gate.sh 输出控制台表格与 tsv 明细，无批次、无趋势、无版本对比、无报告快照批次看板、趋势、版本对比、报告中心，一次批次一份可归档快照

1.4 一次评测批次的数据流

  1. 用例集冻结：eval_dataset_version 写入 checksum，后续批次引用该版本，不随用例编辑漂移。
  2. 新建批次：写入目标快照，含模型 provider、top-k、min-score、title-gate、提示词哈希、语料版本与工具预算，并复制一份语料库。
  3. 拆解 item：批次按用例逐条生成 eval_item，重复运行生成多个 eval_run，attempt 从 1 递增。
  4. 执行：EvalCaseExecutor 组装合成事件，走真实链路，检索使用只读库副本，出站只做干跑不发送。
  5. 留痕：span 在链路各点开启与关闭，检索快照、工具调用、引用映射分别落明细表。
  6. 提交：整树在一个事务内写入，失败降级为只落 run 摘要并在 error_code 标注 trace_partial。
  7. 判定：规则判定先跑，LLM 判定按 rubric 跑，两者结论写入 eval_judge，不一致进冲突表。
  8. 归因：按决策树产出 eval_failure，每条失败带标签、证据指针与建议动作。
  9. 聚合：批次统计写入 eval_batch.stats，维度与标签聚合进视图表，门禁按基线计算结论。
  10. 出报告：生成不可变快照，报告正文引用批次、基线、告警与失败 Top，落盘并记 digest。

1.5 三条硬约束

约束后果设计应对
单进程单 SQLite，单连接串行写评测写放大会拖慢群问答，甚至触发 WAL 冲突独立 eval 库副本用于执行；结果批写，单批 500 行或 2 秒；默认并发 2；大批次限定在低峰窗口
评测不得污染生产数据评测请求若走 OutboundSender 会真的发到群里，若写 qa_stat 会污染看板出站干跑开关，只走过滤与分片，不调协议客户端；评测不写 qa_*；影子采样只读关联 qa_stat.id
必须复用真实链路另写一套检索或提示词，评测结论与线上必然漂移执行器只做“装配参数 + 开 span”，检索、注入、工具循环、降级全部调用生产类

3.3 通用交互约定

  • 批次、用例、判定、失败四条主线的筛选条件全部进 URL query，可复制、可分享、可回退。
  • 表格分页统一 offset/limit，默认 50 条，上限 500 条；导出走独立接口，不在前端拼 CSV。
  • 所有异步动作返回 202 与资源 id，页面订阅 SSE 进度；断线重连以批次 id 恢复，不重复触发执行。
  • 单用例详情支持 j k 上下条切换，回到列表时保留滚动位置与筛选。
  • 长文本统一折叠前 6 行，展开不重新请求；引用块跳转到知识库对应块，带来源标注。

6.6 复核

入队条件优先级处理要求
判定置信度低于 0.6普通按用例集分配，48 小时内完成
自动判定冲突高24 小时内裁决
安全维度任一失败紧急当日处理，未处理阻止发版
抽检命中普通只校验自动结论，不改写用例
人工主动提交普通备注必填

盲评机制：复核页默认隐藏自动判定与其他人结论，提交后展示对照，避免锚定。争议升级路径为复核人、算法负责人、评测管理员，逐级留痕，升级超过 72 小时自动标记为阻塞项。

6.7 标签治理

标签是归因的词汇表，必须可版本化：新增标签走配置页提交，需说明判定条件与责任模块；废弃标签只停用不删除，历史结论仍可读。标签与判定器解耦，一个判定器可以产出多个标签，一个标签也可由多个判定器共同支撑。

6.8 告警与回归

规则指标阈值动作
质量回退通过率低于基线 3pp阻断发版，生成失败归因摘要
检索回退分类别 R@5任一类别下降 5pp阻断，指向类别用例清单
引用回退引用支持率低于基线 5pp警告，要求复核
稳定性flaky 率高于 5%警告，要求重复运行
延迟P95高于基线 1.5 倍警告
成本单任务成本高于基线 30%警告，列出最贵用例
安全漏拦数大于 0硬阻断，安全负责人必须处置
过程过程完整率低于 98%警告，提示埋点缺失

发版回归固定四步：预检拉取激活基线，执行发版用例集，按三态给出结论，归档报告并写入版本记录。阻断态只能由评测管理员与安全负责人同时确认后解除，解除动作进审计。
