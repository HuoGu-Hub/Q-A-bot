双端功能统计

用途：重新规划 Web 端功能分布时的现状清单 ｜ 2026-09-25 只列功能，不做设计说明。

一、公开站（/）

面向群友。导航 4 项：首页 / 资料库 / 问答广场 / 关于。

1.1 首页 /

功能 说明
数据概览 「这个助手有多少料」—— 问答数、知识库条目、术语数
使用说明 「怎么用」—— 引导去群里 @ 机器人

1.2 资料库 /library

功能 说明
分类浏览 按 Wiki 分类列出条目
关键词搜索 搜条目名

1.3 词条详情 /entry/:title

功能 说明
条目正文 从 Wiki 清洗后的文本
原文链接 跳转到 enshrouded.wiki.gg
不存在兜底 「没有这个词条」

1.4 问答广场 /plaza

功能 说明
热词列表 「大家都在查什么」—— 只显示有获赞答案的词
关键词页 某关键词下 top-3 获赞回答
投票 👍 赞 / 👎 踩 / 🕐 已过时
去重 相似回答合并（相似度 > 0.9）
二级降级 3 条全被踩 → 「问问新答案」（调模型重新生成）
三级降级 再全被踩 → 「求助大佬」（生成文案，让用户复制到群里）
隐私保护 只展示被点赞过的答案

1.5 关于 /about

功能 说明
介绍 飘雪喵是什么
资料来源 Wiki 署名与许可

二、管理后台（/admin/）

导航 9 项。

2.1 数据大屏 /admin/screen

功能 说明
每日提问量 趋势图
检索来源 向量路 / 关键词路占比
关键词排行 被问最多的词

2.2 看板 /admin/dashboard

功能 说明
未命中 · 该补什么 群友问了但知识库查不到的词
关键词排行 同上，带明细
检索来源 / 标注 命中情况
最高余弦分布 阈值参考（调 min-score 用）

2.3 问答记录 /admin/records

功能 说明
记录列表 历史问答，含问题/回答/命中情况
标注 人工标 good / bad

2.4 术语表 /admin/glossary

功能 说明
增删改 中英对照词条（检索 B 路依赖它）
搜索 按中/英文查

2.5 日志 /admin/logs

功能 说明
业务层日志 内存环形缓冲 + SSE 实时推送，级别过滤、搜索、暂停
NapCat 日志 读容器日志文件，文件列表 + 只读尾部
脱敏 token / QQ 号自动打码

2.6 指令 /admin/commands

功能 说明
指令增删改 触发词 + 回复模板
变量插入 点击插入 {user} {time} 等 15 个变量
实时预览 保存前看渲染结果
使用统计 最常用 + 「群友发了但没配」排行

2.7 设置 /admin/settings

功能 说明
Bot 行为配置 31 项，8 组：回复行为 / 频率限制 / 话术 / 功能开关 / 指令系统 / 媒体 / 知识库 / 统计
热生效 保存立即生效，不用重启
白名单 基础设施配置不显示也拒绝写入

2.8 模型 /admin/models

功能 说明
调用链展示 默认 → 降级顺序（只读）
模型 ID 可改 唯一可改项，其余只读
测试连通性 建临时客户端发最小请求
拉取模型列表 调 /v1/models 做下拉
先测再换 测不通拒绝保存
热生效 改完立即生效

2.9 广场 /admin/plaza

功能 说明
概览卡片 投票数 / 已上架 / 该降级 / 求助数 / 今日限额
投票内容 含未上架的（有人在踩但还没上架的，提前发现）
投票明细 谁投的（hash）、什么时候
下架 清空投票 → 自动从公开站消失
求助记录 pending（申请了没发）/ sent

三、功能分布的问题

3.1 公开站

问题 说明
首页内容单薄 只有两个数字块 + 使用说明，没有引导
资料库与问答广场割裂 一个查 Wiki、一个看问答，互相不打通
无搜索入口 首页没有搜索框，要先进资料库
词条页无相关问答 看 Wiki 时看不到「别人问过什么」
广场入口深 导航第 3 项，且要先进关键词列表
移动端未验证 布局是响应式的，但没在手机上试过

3.2 管理后台

问题 说明
导航 9 项偏多 大屏/看板/记录 三者内容有重叠
大屏 vs 看板职责不清 都是统计，一个给"看"一个给"分析"
记录与广场割裂 广场的投票内容也是记录，但分在两个页面
术语表无批量操作 3,282 条，只能一条条改
缺少知识库构建入口 重建索引要跑命令行
无「回答格式」配置 ← 你刚提的需求，目前不存在
