# 知识库运营手册

> **给谁看**：负责让机器人「答得准」的人。**不需要懂编程** —— 全文没有一行代码。
> **看完你会知道**：机器人怎么找资料、现在家底多少、你该做什么、做完怎么验。
>
> 需要敲命令的部分（导入、回滚、体检）单独放在
> 《知识库运维命令速查》—— 那份是给技术同学的。

## 如果你只读一段

> **现在最值钱的一件事：给 651 条资料补上中文名。**
>
> 这些资料**明明在库里，中文提问却永远够不到** —— 因为它们在库里的名字是英文
> （「智力」这条叫 `Intelligence`）。群友问「智力有什么用」，机器人拿着「智力」去找，
> 找不到。
>
> 补中文名**比再抓几百页资料都管用**。怎么做见第四节。

## 一、机器人是怎么回答的

群友问一句，机器人分两步走。

### 第一步：先猜「他在问哪条资料」

两条路**同时**找，谁找到算谁的：

| | 怎么找 | 例子 |
|---|---|---|
| **按名字找** | 问题里出现了资料的名字 | 「**力量**怎么加」→ 找到「力量」这条 |
| **按意思找** | 问题跟哪条资料「讲的是同一件事」 | 「怎么变强」→ 找到「力量」「装备强化」… |

### 第二步：把找到的资料交给 AI，让它照着回答

资料里没有的，它**必须**说「资料里没查到」，不许自己编。

### ★ 关键：为什么有些问题答不上来

**因为资料没有中文名。**

举个例子，「智力」这条资料，它在库里的名字是 **`Intelligence`**（英文）：

```
群友问：「智力有什么用」
机器人拿着「智力」两个字去找
库里那条叫 Intelligence          ← 对不上
按意思找也不行，因为那条路也要求名字出现
                    ↓
        结果：资料明明在库里，就是够不到
```

**这就是目前最大的问题。** 3,416 条资料里有 **651 条（18%）只有英文名**。

> 缺口最大的几个词：**法师（71 次）、技能（44 次）、技能点（28 次）、属性（13 次）、
> 力量（13 次）、智力（10 次）** —— 全都是群友天天问的。
>
> **不是「库里没内容」，是「库里有内容但没有中文名」。**

## 四、补中文名（最要紧的事）

### 怎么做

**在后台点几下就行，不用装任何软件。**

```
① 打开管理后台 → 知识库 → 词条
② 点「无中文名」按钮          → 应该显示 651
③ 再选一个分类，比如「战斗装备」→ 只剩 4 条
④ 点「导出」                   → 得到一个 Excel 文件
⑤ 用 WPS 打开，在「中文名」那一列填上中文
⑥ 回后台点「导入」，选这个文件
⑦ 刷新 → 条数应该减少（651 → 647）
```

> **导入不会覆盖你已经填过的名字**，重复导入是安全的。
> 改完**立即生效，不用重启机器人**。

### 分几批做（从少的开始）

| 批次 | 分类 | 条数 | 说明 |
|---|---|---|---|
| **1** | 战斗装备 | **4** | **先用这 4 条练手**，确认整个流程走得通 |
| 2 | 建造装饰 | 33 | |
| 3 | 敌人生物 | 48 | 狼、蜘蛛、牦牛…大多是普通名词，好填 |
| **4** | **系统机制** | **145** | ← **最值钱**（属性、技能都在这） |
| 5 | 任务剧情 | 416 | 背景故事，群友很少问，可以最后做 |

> 数字是 2026-10-04 的实际情况，补完会变。

### 三条规矩

**① 宁可少填一个，也不要瞎填。**

填错的名字会**污染整个检索** —— 比不填还糟。

| 放心填 | 要查证 |
|---|---|
| 力量、智力、体质、敏捷、耐力 | **技能名**（`Absorb`、`Battle Heal`…） |
| 制作、战斗机制、舒适度、技能点 | 得用**游戏官方中文**，别自己编 |
| 狼、蜘蛛、牦牛、山羊、螃蟹 | 查不到就**留着别填** |

**② 已经填过的不会被覆盖。** 重复导入安全。

**③ 「没有中文名」的标准是「一个汉字都没有」。**

所以 `Bamboo Ladder、Bamboo Ladder` 这种「中文名和别名都是英文」的，**也算没名字**，
也会出现在「无中文名」列表里。

### 做完怎么验

补完**第 4 批（系统机制）**之后，直接在群里问：

> **「智力有什么用」**

| | 应该看到 |
|---|---|
| **补之前** | 机器人说「资料里没查到」 |
| **补之后** | 开始引用资料回答 |

**这是唯一能证明这件事有用的检验。** 不用重启，改完就能试。

## 五、加新资料

两条路**互补**，不是二选一：

| | 从 wiki 自动抓 | 自己写 |
|---|---|---|
| **适合** | 物品、技能、生物、地点 | 攻略、版本更新、易错点 |
| **质量** | 看 wiki 本身 | **我们自己把关** |
| **一次的量** | 几百页 | 几十条 |
| **要不要判断** | 不用 | **要** —— 所以得人写 |

### 自己写的文档

- **格式有要求**（文档头、分块、分类）→ 看《知识库文档格式规范》
- **写完怎么导**：后台 → 知识库 → 文档 → **拖进去**
  - ⚠️ **先点「预览」，再点「导入」** —— 预览会告诉你「新增几条、覆盖几条」
  - 如果预览说「无变化」但你明明改了东西，**停下来问技术同学**

### 从 wiki 抓

需要技术同学执行命令 → 看《知识库运维命令速查》

## 六、日常检查清单

| 什么时候 | 做什么 | 在哪 |
|---|---|---|
| **每次导入资料之后** | 点「补标题向量」 | 后台 → 知识库 → 文档（块面板） |
| **下架 / 清理资料之后** | 点「清理孤儿词条」 | 后台 → 知识库 → 词条 |
| **每月** | 看「哪些问题没答上」 | 后台 → 知识库 → 提案 |
| **每次大改动之后** | 让技术同学跑一次「体检」 | 见《知识库运维命令速查》 |

> **「孤儿词条」是什么**：有些名字是人工先起的（"先起个名，正文以后再导"），
> 长得和"该清理的残留"一模一样。所以**这个按钮要人点**，系统不敢自动删。

## 七、出问题怎么办

| 症状 | 可能原因 | 怎么办 |
|---|---|---|
| 问什么都说「资料里没查到」 | 资料没有中文名 | **补中文名**（第四节） |
| 有些问题答不上，有些能答 | 同上，只有一部分没名字 | 看「提案」面板找没答上的问题 |
| 答的内容是旧的 | 资料本身过期 | 核对那条资料，更新它 |
| 答得很笼统、没细节 | 资料太短 | 补写详细内容 |
| 后台「无中文名」显示 0 | **服务没重启** | 找技术同学重启 |
| 导入时报「编码不对」 | 文件存错了 | **只用后台导出的文件填**，别自己另存 |
| 导入后条数没变 | 预览说「无变化」 | 停下来问技术同学 |
